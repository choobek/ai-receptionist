# Archive

This directory keeps historical call reviews and manual reproduction notes that still matter as project evidence but should not sit beside current operator docs.

- [`real-call-evaluations/`](./real-call-evaluations/) contains dated call reviews and review summaries.
- [`manual-test-scenarios/`](./manual-test-scenarios/) contains one-off or historical manual reproduction scripts.

Use these files for background and regression history, not as the active source of truth for repo operations.
