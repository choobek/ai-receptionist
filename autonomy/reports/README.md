# Reports

Committed audit and design reports can live here.

Generated reports that include real-call details should go under a git-ignored directory such as:

- `autonomy/reports/generated/`

The staging regression suite writes Markdown summaries under:

- `autonomy/reports/generated/staging/`

The guarded staging improvement loop writes Markdown reports and an index under:

- `autonomy/reports/generated/staging-loop/`
